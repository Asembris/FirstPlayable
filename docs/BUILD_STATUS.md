## Same-prefix replay — the central Phase 1 proof

Prefix replayed through the real interpreter from a fresh initial state:
`core.inspect` → `core.ask_context` → `discovery.ask_identity`. The prefix is
legal in both versions.

| Action after that identical prefix | Discovery v1 | Discovery v2 |
|---|---|---|
| `core.give` | **enabled** | **locked** — "Nia refused the letter once you raised the two names." |
| `core.ask_terms` | enabled | enabled |
| `core.withhold` | enabled | enabled |
| `core.leave` | enabled | enabled |

`core.give` is the only action whose availability changed. In v2 `end.give`
remains globally reachable in a minimum of 3 actions, by returning the letter
before the contradiction is raised; the revision removes no ending from the
scene.

`Gate.when` is an **allow** condition throughout the implementation: the gated
action is permitted only while every gate on it evaluates TRUE against the
pre-action state. v1 allows `core.give` after `discovery.disclosed == true`;
v2 allows it while `discovery.disclosed == false`.

## Mechanical versus wording changes

`mechanical_change` is set only when a bounded paired replay demonstrates a
changed legal action availability or a changed reachable-ending set.

| Edit | Classification |
|---|---|
| Discovery v1 → v2 (the gate condition) | mechanical; world, core, and ports unchanged |
| An ending copy override ("make it kinder") | wording only, not mechanical |
| Changed dialogue prose, same structure | wording only, not mechanical; mechanical signature identical |
| A consistently renamed state flag | wording only, not mechanical (the signature differs, which is exactly why the replay witness decides) |
| A changed `reference_id` or approved-text label | wording only, not mechanical |

Nothing in the diff calls a model. All labels come from structural comparison
and replay.

## Failure behaviour that was verified

Rejected by the strict contract: unknown fields at the root and nested, verbs
outside the five-verb vocabulary, a verb pointed at the wrong entity kind,
malformed identifiers, condition expression strings, empty/over-long/duplicate/
contradictory condition clauses, effects other than `set_true`, a variable that
does not start false, over-budget core and module variables and actions, more
than three branches, a second NPC, anything other than three endings, oversized
text, control characters, and two modules in one slot.

Rejected by the validator: `NO_PROGRESS`, `SOFTLOCK`, `ENDING_UNREACHABLE`,
`DEAD_ACTION`, `DEAD_BRANCH`, `GATE_NEVER_BLOCKS`, `DEAD_HOOK`,

`NAMESPACE_INVALID`, `ENDING_UNRESOLVED`, `DIALOGUE_UNRESOLVED`,
`VAR_UNRESOLVED`, `TARGET_UNRESOLVED`, `SPEAKER_UNRESOLVED`,
`GATE_ACTION_UNRESOLVED`, `RESERVED_SPEAKER_COLLISION`,

## Known limitations of Phase 1

1. **No external authority.** `validateScene` can prove a scene is internally
   consistent and that its approvals are in a supplied allowlist, but Phase 1
   has no frozen database snapshot. With no allowlist the report says so in its
   notes rather than implying authority was checked. A Qloo-grounded badge
   cannot be issued here and is not issued.
2. **Commitment slot unexercised by a fixture.** The Commitment port rules,
   namespace, gate targets, and hook target are implemented and enforced, and
   cross-slot isolation is tested with a synthetic Commitment module, but no
   hand-authored Commitment fixture exists. Only two module subsets therefore
   exist per version instead of four.
3. **Writing is not final.** The fixture is the specification's short design
   fixture, not a human-playtested 2–4 minute experience. The validator proves
   no creative quality, and Layer C is deliberately absent.
4. **The player is minimal.** `/example` is readable and usable, with a
   transcript, locked-choice explanations, reset, and version switching, but it
   is not the Phase 6 creative-tool polish: no object-opening treatment, no
   provenance drawer, no mobile sheets, no replay control, no compare view.
5. **Hashing is not a security boundary.** `src/engine/hash.ts` is a pure
   SHA-256 over canonical JSON, used for equality of owned objects. It is not a
   signature and proves no authorship.
6. **The graph time ceiling is wall-clock.** The 5-second ceiling can fail a
   validation on a very slow machine. It cannot change the finite-state
   contract, and failure is explicit.
7. **Playwright browser pinning.** The e2e gate requires a chromium matching
   `@playwright/test@1.56.1`.
